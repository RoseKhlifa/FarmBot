# 卡片 PC-05：操作审计

| 调度头 | 值 |
| --- | --- |
| 波次 | **W15** |
| 前置依赖 | P3-02、P6-04（写类管理操作已就位） |
| 独占文件 | `internal/audit/**`（+ 中间件挂钩点） |
| 可与谁并发 | 其它 W15 卡（P7-04 单独收口除外） |
| 风险 | 🟡 低中 |

---

- 目标：留「谁改了谁」的操作证据链（计费纠纷 / 滥用追责）。
- 源（现状缺口）：有登录审计（`login-logs.json`）；无操作审计。
- 目标（Go）：`internal/audit/` + 写类管理操作后落审计的中间件。
- 实现要点：
  - `audit_log` 表：`actor_user, action, target_account, ip, ua, detail_json, ts`（ts 由请求上下文注入，不在写入处取时钟）。
  - 中间件在**写类**管理操作后落审计：谁启停了谁的账号、改了谁的配置、发了多少卡密。
  - 审计**只增不改**；提供管理端查询与按时间导出。
- 不要做：不记录敏感明文（凭据/密码）到 detail_json；不允许修改/删除审计记录。
- 验收：`go test`——写操作产生审计行、只增不改、查询/导出可用。
- 完成判据：☐ audit_log 表 ☐ 写操作落审计 ☐ 只增不改 ☐ 查询+导出 ☐ 无敏感明文。
